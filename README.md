## 在 VS Code 中開啟練習

### 步驟 1：複製（Clone）專案到電腦

1. 打開 **VS Code**。
2. 按下快捷鍵 **`Ctrl + Shift + P`**，輸入 `Git: Clone`。
3. 選擇 **Clone from GitHub**（若尚未登入，請依提示登入）。
4. 在清單中找到並點擊屬於你的專案（例如：`organization/practice-yourname`）。
5. 選擇電腦中的一個資料夾存放（例如：桌面或 D 槽）。
6. 彈出提示時，選擇 **Open (開啟)**。

### 步驟 2：開始編織第一段程式

1. 按下 **`Ctrl + Shift + E`** 開啟左側檔案總管。
2. 建立一個新檔案，命名為 `test.py`。
3. 按下 **`Ctrl + Shift + I`**（Copilot Edits），輸入指令（舉例如下）：
> 「幫我寫一段簡單的 Python 程式，顯示目前的日期與時間，並加上一些漂亮的註解。」


4. 看到 AI 產出後，點擊 **Accept**。

### 步驟 3：存檔並推播（Push）到雲端

1. 點擊左側第三個圖示 **Source Control (原始碼控制)**，或按 `Ctrl + Shift + G`。
2. 在 **Message** 欄位輸入這段動作的說明（例如：`第一次練習 AI 編織`）。
3. 點擊 **Commit (提交)** 按鈕。
4. 最後點擊 **Sync Changes (同步變更)** 或 **Push**。
* 進入GitHub上的 Repo 網頁，也能看到這段程式碼！
